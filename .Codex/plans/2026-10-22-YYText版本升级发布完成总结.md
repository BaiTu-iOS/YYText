## 版本内容

YYTextKeyboardManager 在 iOS 13 及以后通过对应窗口的 windowScene.interfaceOrientation 记录方向；无 Scene 时记录 Unknown。旧系统兼容路径、键盘 frame、动画与观察者通知契约保持原样。

## Review 与验证

- 本次修改及相关键盘调用链未发现可确认的崩溃或行为缺陷；这不等于整个 YYText 的全部功能不会崩溃。
- 定向 XCTest 8/8 通过，包含空 Application、空窗口、无 Scene、窗口选择优先级、连续 10,000 次通知和观察者回调契约。

- 已有 Vone iPhone 15 Plus（iOS 27.0）宿主编译和“我的 → VIP”UI 测试通过。
- 旧系统运行分支未做旧系统真机回归，已完成 iOS 9 deployment target 的 arm64 编译。
- podspec quick lint、Ruby 语法检查及禁止关键词检查通过。

## 实际发布流程

1. Wukong 3.0.35 环境检查通过；用户 Ruby 环境中的 cocoapods-packager 为 2.7.25，cocoapods-publish 为 2.9.6。
2. Wukong --to-github 前端要求 GitHub 发布配置目录，与当前源码标签 fork 布局不匹配，因此没有把该前端执行报告为成功。
3. 用户完成 GitHub 认证并开通 YYText 写权限后，确认远端 main 已包含 5edaa1a；创建并推送 1.0.9.BAITU 标签。
4. 使用 Wukong 底层 cocoapods-publish 引擎执行 `pod publish baitu-specs YYText.podspec --to-github --debug`，退出码 0，明确输出 1.0.9.BAITU 发布成功。
5. GitHub 凭据通过交互式 Shell 和临时 Git credential helper 使用，没有把 Token 写入仓库或日志。
